## 常用的快捷键

### Command + Enter

在有错的地方使用，能够解决错误，如包没有import，接口方法没有实现等等。

### Command + 点击

1. 点击类，进入类
1. 点击变量名，找到它定义的地方
### Command + option + b

找到接口的实现类

### Command + option + 左

在之前查看的地方进行切换

### 搜索

### Command + f

当前文件搜索 

两次shift 全局搜索 

Command + shift + f 可以指定搜索范围为项目、模块、目录等等，最好使

### Debug

### F7

进入方法内部 

### F8 

执行下一条语句，不进入方法内部

## 验证SQL语句

1. 使用dialect配置全局和项目使用的数据库
1. 在右侧Database配置SQL连接
1. 进行同步后就能看到sql语句的正确性（绿字）
## VCS

使用IDEA进行版本管理，主要还是在用Git。 对于目录下有.git文件夹的项目，右上角出现pull pull用来更新项目，把代码库里的项目改动拉下来
commit用来把当前工作区的内容进行保存，保存到stage区。每次commit还可以选择commit+push，把改动更新到远程仓库
history可以查看当前文件的改动历史 revert可以放弃当前文件的工作区改动，把它退回到上一次commit的版本
