# Gflags

## 来源

在Cpp的编码标准中，提到gflags的声明和定义需要放在命名空间中。

## 定义

一个工具包，用来帮助实现命令行中参数配置的。

## 如何使用

1. 添加gflags的依赖
1. 使用`#include <gflags/gflags.h>`添加头文件
1. 使用命名空间
1. 定义参数格式，都是以`DEFINE_`开头，宏的定义格式。支持的数据格式有`bool int32 int64 uint64 double string`
1. 对于公用的数据，将它声明在.h文件中，定义在.cc文件中，使用时`#includes foo.h`；对于不太常用的参数，这样定义会产生一定开销。
1. 定义需要遵循格式 {参数名, 默认值, 说明}
1. 访问参数需要加上固定头`FLAGS_`+参数名
## 额外功能

1. DECLARE的使用 在不同文件中使用Flag，如果未被DEFINE，需要使用DECLARE，才可正常使用。但是推荐只在紧密相关的文件之间使用DECLAR，或者DECLARE在.h文件中，然后#inlcude头文件。
1. 参数校验器 对于传入参数的值，可以使用校验器进行校验。
```c++
// 定义静态函数static bool ValidatePort(const char* flagname, int32 value) {   if (value > 0 && value < 32768)   // value is ok     return true;   printf("Invalid value for --%s: %d\n", flagname, (int)value);   return false;}DEFINE_int32(port, 0, "What port to listen on");// 定义校验器，函数指针作为入参DEFINE_validator(port, &ValidatePort);
```

1. 在参数中使用`-`表示后面的参数无效
1. 对于布尔参数，–noswitch表示false
1. 特别的参数`-fromeenv`表示从环境变量中读取参数，如果参数不存在会产生fatal error；`-tryfromenv`与上面不同是，如果参数不存在会使用默认参数，不产生fatal error；`-flagfile`传入一个文件名
