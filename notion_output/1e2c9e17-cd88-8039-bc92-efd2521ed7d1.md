# 删除双系统
create_time: 2025-04-27T06:34:00.000Z
modify_time: 2025-04-27T06:39:00.000Z

准备使用 Linux 服务器作为远程开发、编译环境使用，废弃笔记本中的 Ubuntu 系统。

### **步骤 1: 备份数据**

在进行任何分区操作之前，确保你已经备份了所有重要数据。分区操作可能会导致数据丢失，因此备份是非常重要的。

### **步骤 2: 启动 Windows**

1. 启动电脑并进入 Windows 系统。
1. 按 `**Win + R**` 打开运行对话框，输入 `**diskmgmt.msc**` 并按回车，打开磁盘管理工具。
### **步骤 3: 删除 Ubuntu 分区**

1. 在磁盘管理工具中，找到 Ubuntu 分区。通常，这些分区是未标记的或标记为 "Linux 文件系统"。
1. 右键点击每个 Ubuntu 分区，然后选择 "删除卷"。这将释放这些分区的空间，使其变为未分配状态。
### **步骤 4: 修复 Windows 引导记录**

### **步骤 5: 合并未分配的空间**

1. 重启进入 Windows 系统后，再次打开磁盘管理工具 (`**diskmgmt.msc**`)。
1. 找到未分配的空间，右键点击相邻的 Windows 分区，然后选择 "扩展卷"。按照向导操作，将未分配的空间合并到现有的 Windows 分区中。
