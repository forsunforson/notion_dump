# 软路由后台下载
create_time: 2025-04-27T07:43:00.000Z
modify_time: 2025-04-27T08:02:00.000Z

目前家庭网络拓扑，使用树莓派作为旁路由，安装 openwrt。

因为百度网盘没有会员的情况下，下载速度只有 100 kb/s，过分慢了。

准备将树莓派用起来，可以当做后台下载工具用，免得需要笔记本一直插着下载。



实现路径

openwrt 通过 docker 安装 kasm + 浏览器 + 下载工具

将 docker 下载目录映射到系统路径下，避免下载文件丢失

通过浏览器访问 docker，下发下载任务



具体步骤

安装 kasm [https://a-nomad.com/download](https://a-nomad.com/download)

映射目录

```bash
docker run -v /path/on/host:/path/in/container my_image
```

登录账号，配置路径
