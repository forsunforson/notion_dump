# 背景

我不止想通过其他人的想法去看待一家公司

也想总结出自己的一套模式

指导思想可能是融合各家所长

处理过程和结论一定要有些自己的东西和沉淀

# 目标

建立多维表格，用于跟踪公司的财报数据，进行可视化

针对每个变动的节点，通过猜测、复盘，给出原因，并进行回顾

建立行业数据库，更深入了解生意模式

给出好团队、好公司、好生意的自己的理解

一套可复用的前置投资筛选模型



# 方案

## 原始数据收集

通过历年财报收集数据

定量数据集

- 收入
- 业务领域
- 成本
- 毛利率
- 
定性数据集

- 致股东的信


最简单的生意模型

收入 - 生产成本 - 固定费用 - 税费 - 一次性费用 = 利润

利润 * 股东回报意愿 = 股东获得的真正现金流



对于公司来说

业务之间是否能相互促进，区分出公司的发展阶段，能看出主营业务，第二增长曲线

毛利率是否稳定且高

固定费用有多固定，是否不随收入规模增加而快速上升，给净利留出空间
