# 初识投资
create_time: 2025-04-22T12:31:00.000Z
modify_time: 2025-12-30T07:24:00.000Z

启动资金来源

考上大学后，家里奖励不少奖金。买数码产品和去西藏旅游花了一部分，大约剩了 8 万下来。



从 0 开始了解投资

在去大学的飞机上，向哥哥咨询该阅读什么书，才能了解投资。哥哥推荐了《聪明的投资者》和《证券分析》。两本大部头一直记在我的阅读清单上，但是真的读完它们，已经是很久之后的事情了。

大学时期读了很多书，关于投资的也不少，但是都一知半解，只能说读完不少，懂的很少。

让我印象比较深的，大约是《漫步华尔街》《随机漫步的傻瓜》一类的书，让我知道市场上充满随机性，想要打败市场获得超额收益是十分困难的。对普通人也有好消息，那就是 ETF。定投指数基金能够轻松的获得平均收益，从美国的股票长期回报率看，有 6-8% 左右。

当然我没有因此放弃主观投资，如果不想打败市场，那各种付出的努力都是没有意义的，年轻人就是要人定胜天，觉得自己一定能成为那个不一样的人。

恰好适逢牛市，在稀里糊涂的过程中，买入了一些银行股，价值股，并且看他们跟随着牛市暴涨

不知道估值的结果就是怎么涨上去又怎么跌回去

虽然能控制住自己，不去追券商，但是最后又全部买入了长安汽车，跟着阿狸学到的第一个教训

再后来，读了一些关于选股的书，类似于费雪的《怎样选择成长股》，水晶苍蝇拍的《股市进阶之道》和《复利信徒》，小小辛巴的《重剑无锋》《百步穿杨》。期望从各种财务指标的数学运算中，找出一些通用规律，从而了解好公司的长相。

水晶苍蝇拍的书，算是给我抄到作业，通过它我看上了广联达，自己选出了百能达

书里提到过的利亚德，我也尝试买入，但是最后觉得估值太高，我也没整明白估值到底是怎么一回事

稍微亏掉点就跑了

这两支股票可能是我的第一次稍微认真的开始买股票，且买入了不算少的金额

在几个 quant 平台，实现了一些算法，用来回测策略

策略大约就是参考格雷厄姆的理念，筛选出一部分低 PB、低 PE 的公司，排除掉一些一次性收入，然后均匀的买入

中间尝试过进行精细化调参，但是发现基本没什么用

用了一点钱执行这个策略，还小赚了一笔

如果追问这个策略到底是怎么赚到钱的，其实因为分散买入的公司有一个踩中了当年风口，雄安概念

猛涨了 50%

认真读了几次《巴菲特致股东的信》、《奥马哈之雾》，想更多了解价值投资。

看更多关于公司的书， 尝试理解买股票就是买公司。

回顾起来，我真是一个很不聪慧的人，其实到现在都不是特别懂公司的估值

对于买入的公司不进行很深入的研究，只会选喜欢的公司管理层，找到一些我认为值得信任的人，看他们对公司的预判和数据分析

这些都没有形成我自己的观点，或者说我只有观点，并没有证据



买股票就是买公司

我到底如何理解这句话？

这句话被巴菲特、段永平等人不断重复。我对它的理解是，股价的最终涨跌，都是来源于公司经营业绩的变化，股票只会有一个最终购买人，就是公司自己

通过识别市场的模式，研究交易对手的变化来尝试从别人的口袋里掏钱，是一件很难的事

因为市场上的人来来去去，市场由公司、基金、散户、做市商、套利者等多种多样的角色构成，构成的比例随时变化

即使短期奏效的方案，中期很可能失效，一旦失效就是面临着亏损的境地

冒着这种风险去做投资，未免成本太高，收益太低了

对长期持有公司的股票来说，最终的收益率会收敛到公司创造的利润上

对很多人来说，炒股是一种消遣，或者说一种跟赌博更接近的活动

资金像风一样，在市场上刮来刮去

大家试图捕捉风向，借助风的力量飞起来

但是风是从哪里刮起来的，风向什么时候会变，这些不可捉摸

可能到最后会发现，原来价值投资者的持股、买入，是牛市的第一声发令枪



市场先生

巴菲特经常把市场拟人化，认为他是双相症病人

在市场里也是摸爬滚打过好一阵子，对这个感受越来越深刻

市场给的报价会在一个宽幅区间波动

我们期望公司股价运行在一个合理轨道，这个轨道是它年均利润增速

最完美的形态，或者叫理性人市场假说里，这个曲线就是预期收益率曲线

很遗憾，理性人假说并不成立

甚至有限理性都很难

因为大家并没有什么共识，如何对公司进行估值，选用多少的折现率，风险补充要多少

所以市场经常会出现极端的波动

按巴菲特说的，即使在有安全边际的情况下，买入之后继续下跌 50% 也是有可能的

但是对于另一部分人来说，市场的出价是一种机会，让你能够根据出价选择卖出或者买入

就跟打德州一样，因为市场太大，一定是有鱼存在的

我们可以只在自己手牌足够大的情况下选择加注

而大部分时间，只要坐着不动就行了，因为在持股的区间内，享受公司业绩增长也很好



记分牌与赛场



什么是懂公司

段永平说巴菲特说的安全边际是到底有多懂公司

他描述中的懂公司，以苹果为例，可以预判苹果会做大屏，不会做汽车

如何总结出一套标准，验证自己是否真的懂公司



目前的审美标准

- 创始人与团队
- 行业与公司位置
- 股东回报
这些都是一票否决制的先决条件
