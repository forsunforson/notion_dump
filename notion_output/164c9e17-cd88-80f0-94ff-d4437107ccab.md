# 背景

LLM 的时代到来，基础模型多种多样，后面可能跟随的是 Agent 的爆发。

对于普通人来说，这个是一个创业的可能性。

如何利用好这个杠杆，为自己创造“睡后收入”，关键在于是否可以把自己的独特能力提供出来。

从另一个角度说，把自己的投资能力体系化论述，才能知道哪里还有问题，查漏补缺一下。

因此考虑将自己的投资思路和历史的 case 进行记录，并尝试训练一个智能体。

# 目标

- 系统化的总结自己的投资哲学来源
- 记录之前的一些投资 case，作为系统学习的案例
- 通过 LLM 语言模型设置一个智能体
# 里程碑

投资哲学来源与体系

投资案例解析，分析这些公司的经过和做出判断的经过
