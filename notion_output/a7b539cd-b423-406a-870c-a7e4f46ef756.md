# goroutines

## 使用

go的协程使用比较简单，直接加上关键词`go`就能用。 它和线程的区别是开销很小，一个新的协程只用3KB左右的内存开销。相比于一个线程按MB算的内存，开销少了不少。 而且它的调度也更轻量级，使用G-P-M模型调度。

```go
func main() {    go func(){        fmt.Println("it's a new goroutine")    }()    fmt.Println("it's main goroutine")}
```

对于协程来说，能够应付90%的并发情况，一般不需要协程池进行数量管控。 但是对于一些极端情况，可能需要限制一下总的协程数。

## 问题排查

通常内存泄漏最容易发生在goroutine中，常用的排查技巧是打出协程堆栈。 在程序中开启pprof后，使用`/pprof/debug/goro`
