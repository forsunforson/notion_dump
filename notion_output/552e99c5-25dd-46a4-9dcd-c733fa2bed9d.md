## 大量数字中最小的k个

### 例题

> 10 亿个数字里里面找最小的 10 个 ### 分析 1. 10亿相当于10的9次方，相当于2G。假设是int数，在java中一个int占32位，4Byte，需要8GB的空间存储。 2. 这种题目第一印象通常是使用排序之后，返回最小的k个值，但是对于大量的数排序开销过高。 3. 第二印象是使用堆，使用小顶堆不用完全排序而输出最小的数。 4. 第三印象是根据分而治之的思路，设置多个小顶堆，每个小顶堆10容量为10。最后进行汇总。 ### 代码 在java中可以使用PriorityQueue实现小顶堆。

```java
    public static int[] findMinTen(int[] arr) {        PriorityQueue<Integer> minHeap = new PriorityQueue<>();        int[] result = new int[10];        for(int i : arr) {            minHeap.offer(i);        }        for(int i=0; i < 10;i++) {            result[i] = minHeap.peek();            minHeap.poll();        }        return result;    }
```

通过传入Comparator接口，重写compare方法能够实现大顶堆。

```java
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(10, new Comparator<Integer>() {            @Override            public int compare(Integer o1, Integer o2) {                return o2 - o1;            }        });
```

也可以自己利用数组实现一个简单的小顶堆。每插入一个数字，在数组尾部插入，进行整理排序；每取出堆顶数字，互换尾部和堆顶，再进行排序整理。

```java
public class MinHeap {    int[] heap;    int last = 0;    MinHeap() {        heap = new int[100];    }    MinHeap(int[] arr) {        heap = arr;    }    void add(int num) {        heap[last++] = num;        sort();    }    int get() {        int result = heap[0];        heap[0] = heap[--last];        sort();        return result;    }    void sort() {        int idx = last - 1;        while (idx > 0) {            if (heap[idx] < heap[idx/2]) {                int tmp = heap[idx];                heap[idx] = heap[idx/2];                heap[idx/2] = tmp;            }            idx = idx / 2;        }    }}
```

```java
    public static int findDuplicatedNum(List<Integer> arr) {        Integer min = arr.get(0);        Integer max = arr.get(0);        for (Integer i : arr) {            if (min > i) {                min = i;            }            if (max < i) {                max = i;            }        }        Integer offset = min;        BitSet bitSet = new BitSet(max - min);        for (Integer i : arr) {            if (bitSet.get(i + offset)) {                return i;            }            else {                bitSet.set(i + offset);            }        }        return -1;    }
```

## 间隔种树

### 例题

输入n代表n种树，输入n个数代表每种树的个数。相邻的树不能相同，输出字典序最小的种法。不存在输出“-”。 ### 分析 找路径或者是找可能性，多用回溯法。对于种树来说，当前的数能不能种，取决于当前树的数量和 ### 代码

```java
import java.util.*;public class Main {    public static void main() {        Scanner sc = new Scanner(System.in);        int n = sc.nextInt();        int[] trees = new int[n];        int sum = 0;        for (int i = 0; i < n; i++) {            trees[i] = sc.nextInt();            sum++;        }        ArrayList<Integer> result = new ArrayList<>();        if (plantTrees(trees, sum, -1, result)) {            for (Integer i : result) {                System.out.print(i + " " );            }        }        else {            System.out.println("-");        }    }    boolean plantTrees(int[] trees, int sum, int pre, List<Integer> result) {        if (sum == 0) {            return true;        }        for (int i = 0; i < trees.length; i++) {            if (trees[i] * 2 > sum + 1) {                return false;            }            if (trees[i] > 0 && i + 1 != pre) {                sum--;                trees[i]--;                result.add(i+1);                if (plantTrees(trees, sum, pre, i+1, result)) {                    return true;                }                sum++;                trees[i]++;                result.remove(result.size()-1);            }        }        return true;    }}
```

### 思考

主要问题是找到判断的出口，当数量最大的树的数量的两倍大于所有数量加一，则没有可行的种树方案。

## 正八边形归零

### 例题

输入一个数组含有八个数，分别是0或1。每次翻转三个数，求让所有数归零最少步骤。 ### 分析 翻转的所有可能性，能转变为树的遍历，分别翻转第一个到第八个数，能够获得8个子结点。对于翻转1号结点的子结点来说，如果它再翻转1号节点，则和父结点结果相同，因此对于子结点来说，可选的翻转对象是剩余的7个结点。 这里说了所有可能的解法，但是要实现最少步骤，使用广度遍历能够降低开销。 ### 代码

```java
public class Main {    public static void main(String[] args) {        ArrayList<Integer> result = new ArrayList<Integer>();        boolean[] visited = new boolean[](8);        findSteps(arr, visited, 0, result);        int min = 8;        for (int i : result) {            min = min > i ? i : min;        }        System.out.println(min);    }    static void findSteps(boolean[] arr, boolean[] visited, int steps, List<Integer> result) {        if (finished(arr)) {            result.add(steps + 1);        }        for (int i = 0; i < 8; i++) {            if (!visited[i]) {                turnover(arr, i);                visited[i] = true;                findSteps(arr, visited, steps + 1, result);                visited[i] = false;            }        }    }    static boolean finished(boolean[] arr) {        for (boolean b : arr) {            if (b) {                return false;            }        }        return true;    }    static void turnover(boolean[] arr, int index) {        int pre = (index + 8 - 1) % 8;        int next = (index + 1) % 8;        arr[pre] = !arr[pre];        arr[index] = !arr[index];        arr[next] = !arr[next];    }}
```

## Trap Rain Water

### 例题

给出一个长度为n的数组，说明使用它最多能够存储多少雨水 ### 分析 能困住多少雨水和左右边界有关，需要两个辅助数组来存储i位置最大左边界和最大右边界，取其中小的边界减去当前值。 ### 代码

```java
public int trapWater(int[] bars) {    int length = bars.length;    int[] left = new int[length];    int[] right = new int[length];    int max = 0;    for (int i = 0; i < length; i++) {        max = max > bars[i] ? max : bars[i];        left[i] = max;    }    max = 0;    for (int i = length - 1; i >= 0; i--) {        max = max > bars[i] ? max : bars[i];        right[i] = max;    }    int water = 0;    for (int i = 0; i < length; i++) {        water += (left[i] < right[i] ? left[i] : right[i]) - bars[i];    }    return water;}
```

```java
int trapWater(int[] bars) {    int l = 0;    int r = bars.length - 1;    int water = 0;    while (l < r) {        if (bars[l] < bars[r]) {            int min = bars[l];            l++;            while (l < r && bars[l] < min) {                water += min - bars[l++];            }        }        else {            int min = bars[r];            r--;            while (l < r && bars[r] < min) {                water += min - bars[r--];            }        }    }    return water;}
```

### 思考

雨水能不能存储取决于两个边界，从左侧开始，如果剩下的边界都不大于它，则最高就是它，否则重新计算左边界。

## 最大连续1的个数

### 例题

给定一个由若干 0 和 1 组成的数组 A，我们最多可以将 K 个值从 0 变成 1 。 返回仅包含 1 的最长（连续）子数组的长度。 ### 分析 最简单的思路是O(n^2)，嵌套遍历两次。 考虑使用双指针，指向数据的前后。 ### 代码

```java
static int longestOnes(int[] A, int K) {        int l = 0;        int r = 0;        int max = 0;        int countZero = 0;        while (r < A.length && l < A.length) {            while (r < A.length && (A[r] != 0 || countZero < K)) {                if (A[r] == 0) {                    countZero++;                }                max = max < r-l+1 ? r-l+1 : max;                r++;            }            if (A[l] == 0) {                countZero--;            }            l++;        }        return max;    }
```

## n！中的0的个数

### 例题

输入一个数字n，判断它的阶乘结果中0的数量 ### 分析 最简单的想法是相乘计算结果，但是复杂度太高。 通过分析发现遇到5的倍数，会产生0。例如n=100，那5的倍数有5，10。。。100，将他们提取出来5*(1,2…20)，后面又有5的倍数。因此计算共有几个5的倍数 ### 代码

```java
static int findZero(int n) {    int count = 0;    int tmp = n;    while (tmp > 0) {        count += tmp / 5;        tmp /= 5;    }    return count;}
```

## 最长公共子序列

给定两个字符串 text1 和 text2，返回这两个字符串的最长公共子序列的长度。 ### 分析 使用动态规划 ### 代码

```java
public int longestCommonSubsequence(String text1, String text2) {        int[][] dp = new int[text1.length()+1][text2.length()+1];        for (int i = 1; i <= text1.length(); i++) {            for (int j = 1; j <= text2.length(); j++) {                if (text1.charAt(i-1) == text2.charAt(j-1)) {                    dp[i][j] = dp[i-1][j-1] + 1;                }                else {                    dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);                }            }        }        return dp[text1.length()][text2.length()];    }
```

## 最长上升子序列

### 例题

给定一个无序的整数数组，找到其中最长上升子序列的长度。 ### 分析 本来以为是连续子序列，这样的话非常简单只要i值小于i-1的值，长度加一。 后来发现是任意子串，那么需要动态规划。对于dp[i]来说，最长的长度应该是比他小的值的长度+1。如此分析之后就能解题。 但是题目要求能否实现O(nlgn)的时间复杂度。这里看完官方的解析，发现需要用贪心加二分查找实现。维持一个d[]数组，新的数字大于末尾数字，数组长度+1；否则替换数组中的数字。 ### 代码 *O*(*n*2)

```java
public int lengthOfLIS(int[] nums) {        if (nums == null || nums.length < 1) {            return 0;        }        int[] dp = new int[nums.length];        dp[0] = 1;        int re = 1;        for (int i = 1; i < nums.length; i++) {            int max = 1;            for (int j = 0; j < i; j++) {                if (nums[j] < nums[i]) {                    max = max < dp[j] + 1 ? dp[j] + 1 : max;                }            }            dp[i] = max;            re = re < max ? max : re;        }        return re;    }
```
