## 替换空格

### 题目描述

> 请实现一个函数，将一个字符串中的每个空格替换成“%20”。例如，当字符串为We Are Happy.则经过替换之后的字符串为We%20Are%20Happy。 ### 分析 这个题目相当于把一个字符替换成3个字符。如果使用原地替换的话，相当于每遇到一个需要替换的字符要移动全字符串一次。倒序遍历就可以避免多次移动字符串。 使用额外空间比较简单，只用遍历过程中，遇到需替换的字符就插入3个字符。 ### 代码

```java
    public static String replaceSpace(StringBuffer str) {        if (str.length() <= 0) {            return "";        }        StringBuffer result = new StringBuffer();        for (int i = str.length() - 1; i >= 0; i--) {            if (str.charAt(i) == ' ') {                result.append("02%");            }            else {                result.append(str.charAt(i));            }        }        return result.reverse().toString();    }
```

### 思考

对于这种遍历字符串，没有思路的时候试试倒序。

## 重建二叉树

### 题目描述

> 输入某二叉树的前序遍历和中序遍历的结果，请重建出该二叉树。假设输入的前序遍历和中序遍历的结果中都不含重复的数字。例如输入前序遍历序列{1,2,4,7,3,5,6,8}和中序遍历序列{4,7,2,1,5,3,8,6}，则重建二叉树并返回。 ### 分析 对于二叉树的题目，使用递归是比较方便的解题方法。 首先要找到递归的边界条件，如果是空数组，说明该结点为空。 先序遍历和中序遍历的规律在，先序遍历的第一个数字一定是根结点，找到中序遍历中根结点的位置，其左边是左子树，右边是右子树。 ### 代码

```java
    public TreeNode reConstructBinaryTree(int [] pre,int [] in) {        if (pre == null || pre.length <= 0 || in == null || in.length <= 0) {            return null;        }        TreeNode root = new TreeNode(pre[0]);        int count = 0;        while (in[count] != pre[0]) {            count++;        }        int[] leftPre = null;        if (count > 0) {            leftPre = Arrays.copyOfRange(pre, 1, count + 1);        }        int[] rightPre = null;        if (count < pre.length) {            rightPre = Arrays.copyOfRange(pre, count+1, pre.length);        }        int[] leftIn = null;        if (count > 0) {            leftIn = Arrays.copyOfRange(in, 0,count);        }        int[] rightIn = null;        if (count < in.length) {            rightIn = Arrays.copyOfRange(in, count+1, in.length);        }        root.left = reConstructBinaryTree(leftPre, leftIn);        root.right = reConstructBinaryTree(rightPre, rightIn);        return root;    }
```

### 思考

需要先考虑递归出口。 其次对于Arrays.copyOfRange(int, from, to)来说，from的数会被复制，to的数不会被复制。

## 用两个栈实现队列

### 题目描述

> 用两个栈来实现一个队列，完成队列的Push和Pop操作。 队列中的元素为int类型。 ### 分析 栈是先进后出，队列是先进先出。 所以将一个栈2专门用来出队，一个栈1专门用来入队。如果栈2为空，就将所有栈1的元素移入栈2再出栈，否则直接出。入栈则直接加入栈1。 ### 代码

```java
    Stack<Integer> stack1 = new Stack<Integer>();    Stack<Integer> stack2 = new Stack<Integer>();    public void push(int node) {        stack1.push(node);        return;    }    public int pop() {        if (!stack2.empty()) {            return stack2.pop();        }        while (!stack1.empty()) {            stack2.push(stack1.pop());        }        return stack2.pop();    }
```

### 思考

这种题目比较简单，需要思考下边界条件，增加代码的容错程度。

## 旋转数组的最小数字

### 题目描述

> 把一个数组最开始的若干个元素搬到数组的末尾，我们称之为数组的旋转。 输入一个非递减排序的数组的一个旋转，输出旋转数组的最小元素。 例如数组{3,4,5,1,2}为{1,2,3,4,5}的一个旋转，该数组的最小值为1。 NOTE：给出的所有元素都大于0，若数组大小为0，请返回0。 ### 分析 这题虽然给了一个旋转数组的概念，但是和旋转数组没什么关系。 对于非递减数组的最小元素，通常是第一个小于前元素的元素。遍历一遍数组也能得出结果。 但是遍历数组时间复杂度为O(n)，本题可以优化为O(logn)。 ### 代码

```java
public int minNumberInRotateArray(int [] array) {    if (array.length == 0) {        return 0;    }    int s = 0;    int e = array.length - 1;    int m = s;    while (array[s] >= array[e]) {        if (e - s == 1) {            m = e;            break;        }        m = (s+e)/2;        if (array[m] >= array[s]) {            s = m;        }        else {            e = m;        }    }    return array[m];}
```

### 思考

虽然只是遍历一个数组，解法十分简单，应该多考虑更高效的解法。

```java
    public int Fibonacci(int n) {        if (n == 0)            return 0;        if (n == 1)            return 1;        return Fibonacci(n-1) + Fibonacci(n-2);    }
```

### 思考

对于题目中特意提出的n小于等于39，限定了数值的范围，可以直接使用递归而不会很慢。否则使用数组记录前值会大大加快速度。

## 跳台阶

### 题目描述

> 一只青蛙一次可以跳上1级台阶，也可以跳上2级。求该青蛙跳上一个n级的台阶总共有多少种跳法（先后次序不同算不同的结果）。 ### 分析 正面分析：假设已知函数F(n)表示跳n格的跳法，第一次跳一格，之后共有F(n-1)；第一次跳二格，之后共有F(n-2)种跳法。本质又是斐波那契。 反面分析：最后一次跳一格或者两个，本质的递推过程和正面分析相同。 ### 代码

```java
    public int JumpFloor(int target) {        if(target == 1) {            return 1;        }        if(target == 2) {            return 2;        }        return JumpFloor(target-1) + JumpFloor(target-2);    }
```
