# Go语言基础

## 介绍

必须包含package，入口方法是main package

```go
package main
```

使用import关键字导入包

```go
import (    "fmt"    "math")//orimport "fmt"import "math"
```

使用导入的变量，需要首字母大写。因为暴露给其他人访问的方法或变量，都使用大写字母开头。

```go
//correctfmt.Println(math.Pi)//errorfmt.Println(math.pi)
```

定义方法，类型在参数名之后

```go
func add(x int, y int) int {    return x + y}//share typefunc add(x, y int) int {    return x + y}
```

方法可以返回多个参数

```go
func swap(x, y string) (string, string) {    return y, x}a, b := swap("a", "b")
```

Naked return用于短方法，指定返回的本地变量名。但是对于较复杂的方法，不推荐这么用，会降低代码可读性。

```go
func split(sum int) (x, y int) {    x = sum / 10    y = sum % 10    return}
```

定义变量，如果有初始化，可以不用指定类型。 使用`:=`可以快速初始化

```go
var a, b, c intvar d, e = false, "true"f := add(1, 2)
```

基本类型 >bool string int int8 int16 int32 int64 uint uint8 uint16 uint32 uint64 uintptr byte // alias for uint8 rune // alias for int32 // represents a Unicode code point float32 float64 complex64 complex128

int uint uintptr根据平台不同，使用32位或者64位

类型强制转换，必须显式指明转换类型

```go
i, j := 3, 4k := math.Sqrt(float64(i*i + j*j))
```

常量设置使用关键字`const`，且不可用`:=`

```go
const i = 1
```

未指定类型的常量，可以根据上下文进行类型转化

指定接收者，可以让接收者直接调用这个方法。

```go
func (m Matcher) Search(feed *Feed, searchTerm string)func (m *Matcher) Search(feed *Feed, searchTerm string)dm := new(Matcher)dm.Search(feed, "test")
```

## 指针

对于函数传参，如果使用值传递，每次函数调用都会在栈上复制一次参数，开销比较大。 go支持c++式的指针传递`foo(&array)`。

## 包管理

对于发布于Git上的Go包，import进来之后，如果在本地查找不到，会使用`go get {git地址}`去下载对应的包。 对于私有域名上的代码仓库，因为访问需要设置代理，因此需要先配置网络proxy。 之后在.ssh文件夹中配置config

并执行命令`chmod 600 ~/.ssh/config`修改config权限为600 在工蜂上配置SSH key 配置git，使用ssh协议访问http/https协议

```plain text
git config --global url."git@xxx.com:".insteadOf https://xxx.com/
git config --global url."git@xxx.com:".insteadOf http://xxx.com/
```

如果get时出`terminal prompts disabled`错误 先执行`export GIT_TERMINAL_PROMPT=1` 再执行`go get -insecure {git地址}`


### 切片

```go
slice := make([]string, 5)  // 创建string切片，长度和容量都是5slice := make([]int, 3, 5)  // 切片长度3，容量5slice := []string{10:"a"}  // 不指定长度，生成的切片slice := []int  // 生成nil切片slice := []int{0,1,2,3,4}newSlice := slice[1:3]  // 从原切片上生成的新切片，从1开始，长度为2，容量为4，不能看到开始位置之前的元素newSlice := slice[2:3:4]  // 切片长度为1，容量为2newSlice := slice[2:4:4]newSlice = append(newSlice, 5)  // 自动扩容至2倍，分配新的底层数组s1 := []int{1,2}s2 := []int{3,4}append(s1, s2...)  // {1,2,3,4}
```

容量指底层数组长度，但是不能访问所有。 对于切片的传值，传递的是本身24字节数据（指针8字节，长度8字节，容量8字节），所以值复制也很快。

使用

```go
newSlice := slice[:3]
```

方式初始化新切片，其底层使用的数组不会复制，开销较小。

切片在函数中为值传递。

### 接口

通过接口的定义，实现多态

```go
package mainimport "fmt"type user struct {    name  string    email string}type admin struct {    person user    super  bool}type notifier interface {    notify()}func (u *user) notify() {    fmt.Printf("I'm a user..\n")}func (a *admin) notify() {    fmt.Printf("I'm an admin..\n")}func sendMsg(n notifier) {    n.notify()}func main() {    u := user{"bob", "bob@tencent.com"}    a := admin{user{"alice", "alice@tencent.com"}, true}    // 接收者一定得是指针    sendMsg(&u)    sendMsg(&a)}
```

也可通过组合实现

```go
type notifier interface {    notify()}func (u *user) notify() {    fmt.Printf("I'm %s.\n", u.name)}func sendMsg(n notifier) {    n.notify()}func main() {    u := user{"bob", "bob@tencent.com"}    a := admin{user{"alice", "alice@tencent.com"}, true}    sendMsg(&u)    // 如果重写了notify方法，则会优先调用admin的notify    sendMsg(&a)}
```

一个接口值是一个两个字长度的数据结构，第一个字包含指向内部表的指针，iTable，包含所存储的值的类型信息；第二个字只想所存储值的指针。

## Goroutine

Go语言负责调度goroutine，会将goroutine放入处理器的执行队列，等待执行。 如果某个goroutine执行阻塞操作，调度器会分离线程和处理器，生成一个新线程使用处理器。 使用命令`go build -race`可以使用竞争检测器分析代码中是否存在资源竞争。

### 原子操作

使用atomic包中的函数可以实现原子操作。 例如`atomic.AddInt64(&count, 1)`可以实现同步加法。`LoadInt64`和`StoreInt64`可以实现安全读写整型。

### 互斥锁

使用sync包中的mutex可以定义互斥锁。

```go
package mainimport (    "sync")var mutex sync.Mutexfunc foo() {    mutex.Lock()    {        // 临界区    }    mutex.Unlock()}
```

### 通道

使用通道能在goroutine之间传递数据，分为有缓冲区和无缓冲区。

```go
unbuffered := make(chan int)buffered := make(chan int, 10)buffered <- 1234value := <- buffered
```

使用无缓冲的通道，两个goroutine在发送或者接收时得阻塞等待。 使用缓冲通道，如果接收者发现缓冲区为空，进行阻塞等待。

读写通道的三种方式

```go
var channel = make(chan int, 10)// 写func write() {    for i:=0; i<100; i++ {        channel <- i    }    // 写完后需要关闭    // 如果不关闭，读写都是goroutine不会报错；但是读在主协程中会报错    close(channel)}// 简单读写func Case1() {    go func () {        for {            value := <- channel            fmt.Println(value)        }    }()    // 即使close掉写的协程，也不会退出读，会一直输出0}// 断言读写func Case2() {    go func () {        for {            if value, ok := <- channel; ok {                fmt.Println(value)            }        }    }()}// range循环func Case3() {    go func () {        for i := range channel {            fmt.Printf("%d\n", i)        }    }()}
```

### 原理

GMP模型
G：Goroutine M：OS底层线程抽象 P：逻辑处理器

并发同步模型：通信顺序进程（Communicating Sequential Processes，CSP） 通过通道传递数据，而不是对数据加锁来实现同步。

## 并发模式

### runner

为了监听程序执行时间，终止超时任务而设计。可用于cron作业，或者基于定时任务的云环境里执行。

```go
type Runner struct {    interrupt chan os.Signal // 接收系统信号    complete chan error // 接收任务执行结果    timeout <-chan time.Time // 超时时间监听    tasks []func(int) // 具体需要执行的任务}func (r *Runner) Start() error {    // 用内部变量接收系统信号    signal.Notify(r.interrupt, os.Interrupt)    // 启动goroutine执行任务    go func() {        r.complete <- r.run()    }()    // 阻塞并且等待    select {    // 处理正常/异常退出    case err := <- r.complete:        return err    // 处理超时    case <- r.timeout:        return ErrTimeout    }}
```

### pool

对于需要共享一组静态资源（共享数据库连接或者内存缓冲区）的情况适用

```go
type Pool struct {    m sync.mutex // 对于池中资源的使用需要加锁    resources chan io.Closer // 存放资源的通道    factory func() (io.Closer, error) // 资源生产工厂    closed bool // 资源池的关闭标识位}// 对应四个操作：创建池、获得资源、释放资源、关闭池func New(fn func() (io.Closer, error), size uint) (*Pool, error) {    // 初始化}func (p *Pool) Acuqure() (io.Closer, error) {    // 通道中存在资源，返回资源    // 通道不存在资源，调用factory方法创建资源}func (p *Pool) Release() {    // 通道未满，放回资源    // 通道已满，释放资源}func (p *Pool) Close() {    p.m.Lock()    defer p.m.Unlock()    // 释放资源，关闭池    p.closed = true    // 关闭通道，再清空资源，否则会发生死锁    close(p.resources)    // 关掉通道还能遍历    for r := range p.resources {        r.Close()    }}
```

### work

使用无缓冲通道创建goroutine池，使用goroutine控制一组工作

## Log

可以用来输出所有日志、重要信息、值得注意的信息和严重问题等。

```go
package mainimport (    "io"    "io/ioutil"    "log"    "os")var (    Trace *log.Logger    Info *log.Logger    Error *log.Logger)func init() {    file, err := os.OpenFile("errors.txt", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)    if err != nil {        log.Fatalln("Failed to open error log file:", err)    }    // 丢弃日志    Trace = log.New(ioutil.Discard, "Trace: ", log.Ldate|log.Ltime|log.Lshorfile)    // 输出日志    Info = log.New(ioutil.Stdout, "Info: ", log.Ldate|log.Ltime|log.Lshorfile)    // 输出到文件    Error = log.New(ioutil.MultiWriter(file, os.Stderr), "Err: ", log.Ldate|log.Ltime|log.Lshorfile)}
```

## 单元测试

### 基础测试

使用一组参数和结果来测试代码。 需要以`_test.go`作为文件结尾。测试方法必须是公开方法，测试方法以`Test`开头，方法签名为`testing.T`的指针，并且不返回任何值。 使用`go test -v`来执行测试程序，`-v`是输出额外信息。

```go
package example1import (
    "net/http"
    "testing"  // 必须导入testing包
)
const checkMark = "\u2713"  // 通过符号
const ballotX = "\u2717"  // 不通过符号
func TestFoo(t *testing.T) {
    t.Logf()  // 输出正常信息
    t.Errorf()  // 输出错误信息
    t.Fatal()  // 输出致命错误
}
```

### 表组测试

TDD，和基础测试类似，但是使用了多组参数和结果。

### 模仿测试

用一些方法模拟代码需要用到的外部资源，比如数据库或网络服务器等。 例如`httptest`包可以模拟HTTP网络调用。

```go
package example2import (    "net/http"    "net/http/httptest"    "testing")const checkMark = "\u2713"  // 通过符号const ballotX = "\u2717"  // 不通过符号func mockServer() *httptest.Server {    f := func(w http.ResponseWriter, r *http.Request) {        //  具体返回的数据    }    return httptest.NewServer(http.HandlerFunc(f))}func TestFoo(t *testing.T) {    server := mockServer()    defer server.Close()    // 测试逻辑}
```

一般定义了接口后，可以使用`mockgen`工具自动生成mock对象，方便其他人写单元测试。

```plain text
mockgen -source=xx_trpc.go -destination=xx_trpc_mock.go -package=包名
```
