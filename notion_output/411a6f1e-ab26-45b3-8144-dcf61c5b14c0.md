## 介绍

类似于Make，Maven，Gradle的包管理工具

## 使用

1. 在根目录下建立WORKSPACE文件，用以标志根目录。对于本地依赖，该文件为空；对于外部依赖，需要在文件中注明
1. 在BUILD文件中，配置需要build的文件，具体使用根据场景不同而不同
1. 使用命令`bazel build //main:myproject`build项目
1. 在根目录下的`bazel-bin/main/myproject`中存储着build后的文件
1. 使用命令`bazel query --notool_deps --noimplicit_deps "deps(//main:myproject)" --output graph`输出依赖图的代码，可在[Graphviz](http://www.webgraphviz.com/)中将其可视化
## 场景

### 1 同一package单一binary

该场景下，WORKSPACE文件为空，BUILD文件中只需填写本工程的信息。

```plain text
// 加载规则bzl文件
load("@rules_cc//cc:defs.bzl", "cc_binary")

// 工程名，工程源文件
cc_binary(
    name = "hello-world",
    srcs = ["hello-world.cc",
    "hello-test.cc",
    "hello-test.h"],
)
```

尝试着直接在srcs中添加多个文件，能够正确完成build。 对于目录中WORKSPACE所在的位置为根目录位置，`#include ".h"`所写的目录位置以根目录位置为准。 `cc_binary`不支持hdrs关键字。 ### 2 同一package多个library 该场景下，WORKSPACE文件也为空，BUILD文件中不仅要填写本工程的信息，还要填写依赖项目的信息。 所有文件都放在main文件夹下。

```plain text
// 相比场景1多了cc_library
load("@rules_cc//cc:defs.bzl", "cc_binary", "cc_library")

// 支持的lib名，源文件，头文件
cc_library(
    name = "hello-greet",
    srcs = ["hello-greet.cc"],
    hdrs = ["hello-greet.h"],
)

cc_library(
    name = "hello-greeting",
    srcs = ["hello-greeting.cc"],
    hdrs = ["hello-greeting.h"],
)

// deps表示依赖的lib信息
// 同一个package下，package名可省略
cc_binary(
    name = "hello-world",
    srcs = ["hello-world.cc"],
    deps = [
        ":hello-greet",
        ":hello-greeting"
    ],
)
```

### 3 多个package多个library

在WORKSPACE同级目录下，存在main文件夹和lib文件夹，表示不同的package。 再每个文件夹下，存在着独立的BUILD文件。

```plain text
// lib下的BUILD配置
load("@rules_cc//cc:defs.bzl", "cc_library")

cc_library(
    name = "hello-time",
    srcs = ["hello-time.cc"],
    hdrs = ["hello-time.h"],
    // 可见性配置，默认文件可见性在本包内，共享同一个BUILD文件
    visibility = ["//main:__pkg__"],
)
```

```plain text
// main下的BUILD配置
load("@rules_cc//cc:defs.bzl", "cc_binary", "cc_library")

cc_library(
    name = "hello-greet",
    srcs = ["hello-greet.cc"],
    hdrs = ["hello-greet.h"],
)

// 不同package，包名不可省略
cc_binary(
    name = "hello-world",
    srcs = ["hello-world.cc"],
    deps = [
        ":hello-greet",
        "//lib:hello-time",
    ],
)
```

### 本地外部项目

本地项目使用local_repository，该功能是内置的功能，具体功能见[手册](https://docs.bazel.build/versions/master/be/workspace.html) 需要在本项目的WORKSPACE文件中配置外部项目地址

```plain text
workspace(name = "myproject")
// 通过使用@coworkers_project//foo:bar来使用项目中的服务
// 针对本地的bazel项目
local_repository(
    name = "coworkers_project",
    path = "/path/coworkers-project",
)
// 针对本地的非bazel项目，需要新建bazel
new_local_repository(
    name = "coworkers_project",
    path = "/path/coworkers-project",
    // 指定本项目中存储的BUILD文件
    build_file = "coworker.BUILD"
)
```

build_file可以参考如下内容，或者新建空的BUILD文件

```plain text
cc_library(
    name = "some-lib",
    srcs = glob(["**"]),
    visibility = ["//visibility:public"],
)
```

### 远程外部项目

远程项目支持[git_repository](https://docs.bazel.build/versions/master/repo/git.html)，[http_archive](https://docs.bazel.build/versions/master/repo/http.html) 通过`@bazel_tools//tools/build_defs/repo:git.bzl`和`@bazel_tools//tools/build_defs/repo:http.bzl`引入支持 推荐使用http协议，支持的文件格式有：“zip”, “jar”, “war”, “tar”, “tar.gz”, “tgz”, “tar.xz”, “tar.bz2” 在本项目的WORKSPACE下引入远程（bazel或者非bazel）项目

```plain text
load("@bazel_tools//tools/build_defs/repo:http.bzl", "http_archive")

// 远程bazel项目
http_archive(
    name = "com_google_absl",
    // 使用sha256指定版本，否则使用最新版本
    sha256 = "84b4277a9b56f9a192952beca535313497826c6ff2e38b2cac7351a3ed2ae780",
    strip_prefix = "abseil-cpp-c476da141ca9cffc2137baf85872f0cae9ffa9ad",
    url = "https://github.com/abseil/abseil-cpp/archive/c476da141ca9cffc2137baf85872f0cae9ffa9ad.zip",
)

// 远程非bazel项目
http_archive(
    name = "zlib",
    // 二选一，使用build文件或者直接写build内容
    #build_file = "//:zlib.BUILD.bazel",
    // 定义build文件内容
    build_file_content = """
    cc_library(
        name = "zlib",
        srcs = glob(["*.c", "*.h"]),
        includes = ["."],
        visibility = ["//visibility:public"],
    )
    """,
    sha256 = "c3e5e9fdd5004dcb542feda5ee4f0ff0744628baf8ed2dd5d66f8ca1197cb1a1",
    strip_prefix = "zlib-1.2.11",
    urls = ["https://mirror.bazel.build/zlib.net/zlib-1.2.11.tar.gz"],
)
```

WORKSPACE文件中的内容，可以提取进行封装。

依赖同软件不同版本的解决方案

```plain text
workspace(name = "myproject")

load("@bazel_tools//tools/build_defs/repo:http.bzl", "http_archive")
http_archive(
    name = "testrunner-v1",
    urls = ["https://github.com/testrunner/v1.zip"],
    sha256 = "..."
)
http_archive(
    name = "testrunner-v2",
    urls = ["https://github.com/testrunner/v2.zip"],
    sha256 = "..."
)
local_repository(
    name = "A",
    path = "../A",
    // 绑定特定版本
    repo_mapping = {"@testrunner" : "@testrunner-v1"}
)
local_repository(
    name = "B",
    path = "../B",
    repo_mapping = {"@testrunner" : "@testrunner-v2"}
)
```
