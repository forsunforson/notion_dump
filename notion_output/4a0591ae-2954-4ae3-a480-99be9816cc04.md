## Socket编程

### 简介

Socket 是对 TCP/IP 协议族的一种封装，是应用层与TCP/IP协议族通信的中间软件抽象层。

从设计模式的角度看来，Socket其实就是一个门面模式（Facade），它把复杂的TCP/IP协议族隐藏在Socket接口后面，对用户来说，一组简单的接口就是全部，让Socket去组织数据，以符合指定的协议。

Socket 还可以认为是一种网络间不同计算机上的进程通信的一种方法，利用三元组（ip地址，协议，端口）就可以唯一标识网络中的进程，网络中的进程通信可以利用这个标志与其它进程进行交互。对于单机来说，也可以利用socket进行通信，将ip地址设为本地地址，如127.0.0.1，就可以实现本机不同进程之间进行通信。

Socket可分为基于TCP和基于UDP两种。 |比较|UDP|TCP| |:—:|:—:|:—:| |传输的数据|每个数据包附带本机和接收端的socket描述符|先建立连建再通信，有建立连接的开销| |数据报|64KB大小限制|无限制| |是否可靠|不可靠，不按顺序|可靠，收发顺序一致| |适用场景|远程登陆，文件传输等数据大小不确定的场景|实时性高或丢包不重要的场景| |粘包问题|不存在|存在|

粘包问题本质是不存在的。但是因为程序实现的原因，导致出现这样的现象。对于UDP来说，每个数据报和数据报之间有明确的间隔，所以不存在粘包问题。对于TCP来说，程序不能及时从缓冲区读取数据，导致两个报文内容无法区分界限，导致粘包问题。使用nagle算法虽然能改进传输效率，但可能会导致粘包问题。因为它原理大致是将多个小的数据报拼接成大的数据报发送。 ### WebServer 一个简易的 Server 的流程如下： 1.建立连接，接受一个客户端连接。
2.接受请求，从网络中读取一条 HTTP 请求报文。
3.处理请求，访问资源。
4.构建响应，创建带有 header 的 HTTP 响应报文。
5.发送响应，传给客户端。

TCP使用的socket方法：
socket() 创建套接字
bind() 分配套接字地址
listen() 等待连接请求
accept() 允许连接请求
read()/write() 数据交换
close() 关闭连接

UDP使用的socket方法：
sendto()/recvfrom() 对应TCP中read()/write()方法
不使用listen() connect()方法
使用一个套接字，就可以完成向任意目标地址传输信息的目的。

以port=5299为例，对于Server的使用流程，可概括为
1 调用socket()创建套接字；
2 使用bind()方法，监听本机上的端口，因为有的服务器有多个ip，可以使用监听所有ip的5299端口；
3 对于某些构造器来说，在初始化的过程中就需传入套接字标识符，并内部调用bind()方法完成初始化；
4 当监听到该端口上有连接请求时，使用accept()允许请求；
5 对于单线程来说，使用该线程完成socket连接，并处理请/对于多线程来说，创造新的socket完成连接，处理请求；
6 处理完毕后，单线程循环监听/多线程关闭创建的socket；
7 关闭服务端socket。

ServerSocket server = new ServerSocket(port);// 单线程的实现监听某一端口Socket socket = server.accept();// 多线程监听某一端口public class ServerThread implements Runnable {    private Socket client = null;    public ServerThread(Socket client){        this.client = client;    }    @Override    public void run() {        try {            // do something about client        } catch (Exception ex) {            // deal with exception        } finally {            client.close();        }    }}Socket client = null;while (true) {    client = server.accept();    // 这里可以使用线程池来减少创建线程的开销    new Thread(new ServerThread(client)).start();}server.close();

### UDP

```java
public class UdpServer {    public static void main(String[] args) throws Exception{        DatagramSocket socket = new DatagramSocket(5299);        byte[] buffer = new byte[1024];        DatagramPacket packet = new DatagramPacket(buffer, 1024);        System.out.println("UDP服务器已启动");        socket.receive(packet);        String string = new String(packet.getData(), 0, packet.getLength());        System.out.println("接收消息：" + string);        byte[] output = "成功接收消息".getBytes();        DatagramPacket packet2 = new DatagramPacket(output, output.length, packet.getAddress(), packet.getPort());        socket.send(packet2);        socket.close();    }}
```

```java
public class UdpClient {    public static void main(String[] args) throws Exception{        InetAddress address = InetAddress.getByName("localhost");        int port = 5299;        DatagramSocket socket = new DatagramSocket();        byte[] output = "发送UDP报文".getBytes();        DatagramPacket packet = new DatagramPacket(output, output.length, address, port);        socket.send(packet);        byte[] input = new byte[1024];        DatagramPacket packet1 = new DatagramPacket(input, 1024);        socket.receive(packet1);        String string = new String(input, 0, packet1.getLength());        System.out.println("接收报文:" + string);        socket.close();    }}
```
