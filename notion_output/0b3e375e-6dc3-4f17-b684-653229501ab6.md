# 网络是怎样连接的

对于计算机中所有的软件硬件来说，每层只干一件事情。 浏览器只负责拼接请求，调用系统的网络接口发送请求。 系统的网络接口里面实现一个协议栈，将请求层层包装，利用利用网络适配器发送出去。 在网络中的集线器、路由器，根据数据包的地址发送数据包。 接受方的事情和发送方的类似，只是反向。

URL中的www，以前说表示world wide web的缩写。实际并没有这个意思，只是大家习惯以3w开头，就形成了习惯。

DNS服务器中，存储的数据格式[域名，Class， 记录类型]。互联网对应的Class为IN，以前设计时为多种设计网络设计，现在都归并到互联网下。记录类型多为A和MX，分别为网站和邮箱。还有用于IP反查域名的PTR，域名别名的CNAME，DNS服务器IP的NS，查询域名属性的SOA。

TCP协议被抽象为套接字（Socket），意为创造一种管道数据传输的概念。 需要四步： 1. 创建套接字（gethostbyname） 2. 连接到服务器套接字上（connect） 3. 收发数据（write read） 4. 断开连接，删除套接字（close）

在计算机的视角，程序的运行是控制权的转移。

在Windows中，套接字的状况可以使用

```shell
netstat -ano
```

在Linux中使用

```shell
netstat -a -p tcp
```

未确定地址的连接显示0.0.0.0:[端口]，UDP显示远程地址为* : *

协议栈如何确定发送数据的时机： 1. 网络包容纳量，不满不发。为了减少固定头部开销。增加效率 2. 时间，过了一定时间，一定得发。降低延迟

合并窗口和ACK的包，能够降低网络开销。

断开连接后，会保留套接字一段时间，为了防止误操作。

网络通讯信号的问题，是不好识别编码，所以需要时钟信号。若分别传输，又会产生信号偏移的问题。为了解决这一问题，才设计出数据信号叠加时钟信号。为了识别时钟信号，需要在MAC帧中添加报头。

交换机根据MAC地址转发端口，分为全双工和半双工模式。全双工不用进行碰撞检查，效率更高。每个端口没有自己的MAC地址，地址表里存着连接设备的MAC地址。

网卡上的LED灯变绿是检查到交换机的连接脉冲。

路由器每个端口有IP和MAC地址，转发包会将源设为自己。可以连接异构网络。

家庭网络由ADSL连接，发送给服务商的数据包会增加MAC头部、PPPoE头部、PPP头部。调制解调器使用ASK和PSK对数字信号进行调频。使用多个频段的信号合成，本质是傅立叶变换。小时候打电话没有网的情况，就是Modem里面没有信号分离器。会导致上网时候电话有杂音，打电话就会断网。

BAS负责将ATM信元还原成网络包并转发到互联网内部。
